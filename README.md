# Hotel Management System

## Project Description

Hotel Management System is a Python-based desktop application developed using Tkinter. It helps manage hotel booking records through a simple and user-friendly graphical interface.

## Features

- Admin Login System
- Add New Booking
- View All Booking Records
- Search Booking Records
- Update Booking Details
- Delete Booking Records
- Excel File Storage
- Logout Functionality
- Duplicate Booking ID Checking

## Booking Details

The system stores:

- Booking ID
- Guest Name
- Phone Number
- Room Number
- Room Type
- Check-in Date
- Check-out Date
- Number of Guests
- Amount

## Technologies Used

- Python
- Tkinter
- OpenPyXL
- Excel
- OS Module

## Data Storage

All booking records are automatically stored in an Excel file named:

hotel_data.xlsx
